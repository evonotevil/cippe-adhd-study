## Priority findings

### P1

- Light and eye-care focus rings are below the 3:1 component contrast target (`src/index.css`).
- SPA view changes do not move focus or announce the new page (`src/App.tsx`, `src/components/ui/PageTransition.tsx`).
- Large text does not scale unclassed option and Topic text (`src/index.css`, `src/components/QuizCard.tsx`, `src/components/TopicPicker.tsx`).
- Idle timer duration can remain stale after settings change (`src/hooks/useTimer.ts`).
- The complete question bank and full Motion feature set ship in the initial bundle (`src/App.tsx` and Motion consumers).
- Cloud sync falls back to a client-side placeholder master key (`src/hooks/useCloudSync.ts`).

### P2

- Locked achievement status text has insufficient contrast at 11px (`src/components/Achievements.tsx`).
- Dark theme is applied inside the app rather than on the document canvas (`src/App.tsx`).
- Import validation checks shapes but not value ranges or cross-field constraints (`src/components/Settings.tsx`).
- Practice state serializes to local storage every second (`src/components/PracticeView.tsx`, `src/hooks/useLocalStorage.ts`).
- The hidden paused timer wakes every 250ms (`src/hooks/useTimer.ts`).
- Learning state is rebuilt multiple times for each progress update (`src/hooks/useProgress.ts`, `src/domain/practice.ts`).

### P3

- Some mobile setting controls have a touch target below 44px (`src/components/Settings.tsx`).
- `date-fns`, `howler`, and `@types/howler` are unused.

## Positive evidence

- Semantic color tokens cover light, dark, and eye-care themes.
- Native controls, field groups, labels, progress ARIA, and reduced-motion handling are generally sound.
- 390px mobile and 200% zoom checks showed no horizontal overflow.
- Production dependency audit reported zero known vulnerabilities.

## Recommended order

Typography coverage and page semantics first, then first-run activation, followed by question-bank splitting, Motion lazy loading, timer/session work reduction, derived-state reuse, and dependency cleanup.
